# Task Management App
A scalable, microservices-based app for managing tasks, built with Node.js, PostgreSQL, MongoDB, AWS SQS, and React. Designed to showcase software architecture skills.

## Architecture
- Microservices: User, Task, Category, Notification.
- Deployed on AWS (ECS, API Gateway, SQS).
- Databases: PostgreSQL (User, Task, Category), MongoDB (Notification).
